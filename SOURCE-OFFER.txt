SwooshDrop 0.3.7 beta - corresponding source

The Windows frontend, packaging, protocol patches, build scripts,
configuration, retained licenses and pinned revisions for this build are at:
https://github.com/AlbinoPriest/swooshdrop/tree/v0.3.7

The matching corresponding-source.tar.gz archive is provided at no charge
as a separate release asset on the same release page as the installer:
https://github.com/AlbinoPriest/swooshdrop/releases/tag/v0.3.7
https://github.com/AlbinoPriest/swooshdrop/releases/download/v0.3.7/corresponding-source.tar.gz

It includes OWL, Linux kernel and driver sources and every WinDrop protocol
patch listed in patches/series, with build instructions. Apply the complete
patch series in order. The archive can be generated with:
  bash scripts/build-corresponding-source.sh
Original component licenses and copyright notices are retained.
