SwooshDrop 0.3.7 integration preview - corresponding source

This is an unreleased development build. It is not a published beta installer.
Windows frontend, packaging, protocol patches, build scripts, configuration,
retained licenses and pinned dependency revisions for this integration are at:
https://github.com/AlbinoPriest/swooshdrop/tree/integrate-kuida-contributions

Build the complete corresponding-source.tar.gz archive with:
  bash scripts/build-corresponding-source.sh
The archive includes OWL, Linux kernel and driver sources and every WinDrop
protocol patch listed in patches/series, with build instructions.

Before distributing a release installer, publish its matching archive as a
separate release asset at no charge on the same release page as the installer:
https://github.com/AlbinoPriest/swooshdrop/releases
Do not distribute this preview installer without its corresponding sources.
